# Информационная система мониторинга и категоризации вторичного сырья «Эко-Навигатор Минск»

Программный комплекс представляет собой десктопное ГИС-приложение для краудсорсингового экологического мониторинга, диспетчеризации вывоза отходов и бизнес-аналитики инфраструктуры раздельного сбора мусора в городе Минске.

## Архитектура и паттерны проектирования

Приложение спроектировано по принципам **чистой архитектуры (Clean Architecture)** и строго разделено на слои, что минимизирует связность компонентов (Закон Деметры) и удовлетворяет критериям SOLID:

*   **Domain (Доменная модель):** Бизнес-сущности `EcoPoint` и `Review`, инкапсулирующие в себе ключевую математическую логику системы (файл `domain/models.py`).
*   **Infrastructure (Инфраструктурный слой):** Доступ к СУБД SQLite через паттерн **Repository** (`infrastructure/repos.py`), инициализация таблиц (`infrastructure/database.py`), контроллеры прямых SQL-транзакций (`infrastructure/db_manager.py`) и локальное геокодирование (`infrastructure/geocoder.py`).
*   **UI / Presentation Layer (Интерфейс):** Построен на базе библиотеки `CustomTkinter` и `TkinterMapView`. Верстка панелей ролей вынесена в отдельные изолированные компоненты (`ui/`), а обработка интерактивных событий карты делегирована выделенному классу `MapController` (паттерн **Delegation**).

## Математическая модель экспоненциального затухания

Для решения проблемы временного лага и неактуальности пользовательских данных в ИС интегрирована математическая модель экспоненциального затухания отзывов:

W = e^(-λ*t)

Где:
*   W — вес (актуальность) конкретного отзыва жителя.
*   λ — коэффициент затухания (в системе принят за `0.05`).
*   t — время в часах, прошедшее с момента отправки отзыва до текущего момента.

Индекс надежности пункта (R, %) динамически рассчитывается как средневзвешенное значение всех состояний бака. Отзывы, оставленные недавно, имеют решающий вес, а устаревшие сигналы автоматически теряют влияние, что позволяет динамически изменять цвет кружков-маркеров на карте в режиме реального времени.

## Ролевая модель доступа (Use Cases)

Система поддерживает 4 типа пользователей со сквозной верификацией прав:

1.  **Физ. Лицо (Горожанин):** Просмотр карты Минска в виде аккуратных цветных кружков. При клике ЛКМ открывается окно с точным текстовым адресом, перечнем принимаемых материалов на человеческом языке и индексом надежности. Доступна отправка крауд-сигналов о состоянии бака.
2.  **Юр. Лицо (Спецтехника):** Режим обслуживания. Позволяет в один клик по маркеру направить мусоровоз, очистить баки от отходов и автоматически сбросить аварийные жалобы жителей, возвращая пункту 100% надежность (зеленый цвет).
3.  **Владелец (Инвестор):** Защищенный B2B-кабинет (`bel123`, `line123`, `chermet123`). Отображает изолированную бизнес-аналитику заполненности инфраструктуры строго для конкретной компании (общее число объектов в собственности и количество баков, требующих немедленной очистки).
4.  **Модератор (Администратор):** Доступ по паролю `admin123`. Инструменты расширения ГИС-сети: ПКМ по карте автоматически вызывает обратный геокодер для определения улицы и дома Минска, позволяет категоризировать типы сырья в регистронезависимых кодах (PET-01, PAP-20) и закрепить пункт за владельцем. Доступен быстрый демонтаж (удаление) точек через клик.

## Инструкция по развертыванию и запуску

### Запуск из среды разработки (Python)
1. Установите зависимости:
   ```bash
   pip install customtkinter tkintermapview geopy pillow
   ```

2. Запустите графический интерфейс:
   ```bash
   python app_gui.py
   ```

### Автономный запуск (Windows)
Запуск скомпилированного автономного приложения выполняется через двойной клик по исполняемому файлу:
*   `dist/app_gui.exe` (Файл должен находиться в одной директории с папками `ui/`, `infrastructure/` и локальной базой данных `ecology.db`).
